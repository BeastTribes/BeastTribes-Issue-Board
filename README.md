# BeastTribes Issue Board
Issues and feature requests board for the BeastTribes Valheim Mod

How to use:

1. Navigate to the [Issues](https://github.com/BeastTribes/BeastTribes-Issue-Board/issues) tab above
2. Check to see if your issue or feature request isn't already there
3. If it doesn't exist, create an issue or feature request with as much detail as possible

Feel free to join us on [our Discord](https://discord.gg/zHGw2u9yPq) if you want to engage further.
